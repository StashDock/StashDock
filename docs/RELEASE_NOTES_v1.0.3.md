# StashDock 1.0.3 for Windows

Fixes an issue where **Rename tag** and **Remove tag** in the Desktop sidebar
could appear unresponsive. Tag menus now open their editors normally while
empty grey areas remain draggable.

Download **StashDock_1.0.3_x64-setup.exe** for Windows 10 or 11, x64.
Your existing library and tags are preserved.

- Windows ChatGPT plugin: 1.0.1 (unchanged).
- Chrome extension: 1.0.0 (unchanged; available in the Chrome Web Store).
- Mac Desktop and plugin: use the existing [Mac downloads](https://github.com/StashDock/StashDock/releases/tag/v1.0.0).

Desktop 1.0.3 and the source at this tag use **GNU AGPL v3 only**.
Previously released MIT versions, including the unchanged plugin and extension
archives, retain their original license. See [Licensing details](https://github.com/StashDock/StashDock/blob/v1.0.3/LICENSING.md).

Windows may show SmartScreen on first launch. See the
[installation guide](https://stashdock.app/guide) for setup and usage.

`SHA256SUMS.txt` contains checksums for the release downloads.
