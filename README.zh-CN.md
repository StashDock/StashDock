## 让有用的上下文，随时找得到、用得上

一篇想给 AI 参考的网页，可能在浏览器收藏夹里；项目文件放在电脑文件夹，调好的 Prompt 则留在某次旧对话中。需要它们时，还得想起存在哪里，再逐一找出来、带进对话。

StashDock 把这些值得复用的上下文收进一个本地个人收藏库。通过可视化卡片认出资料，用快捷搜索找到需要的内容，按自己的习惯整理，再交给正在使用的 AI。

## ChatGPT 插件：收藏库就在对话旁

安装 **StashDock ChatGPT 插件**，即可在对话旁的侧边栏打开收藏库。边聊边浏览和管理参考，选中需要的内容，点击 **Add to chat（添加到对话）** 即可加入当前聊天。

![选择收藏并添加到 AI 对话](assets/readme/ai-sidebar.gif)

## 独立桌面应用：把上下文带进任意 AI

你也可以下载 **StashDock Desktop**，在 Windows 或 Mac 上使用独立桌面应用。打开收藏库面板，浏览、整理和选择参考，再复制或拖入任意 AI 应用。

把悬浮文件夹移到正在使用的应用旁，悬停即可快捷搜索，找到参考直接拖进对话；点击文件夹则展开完整收藏库。

![搜索、滚动浏览卡片、拖入 AI，再打开完整收藏库](assets/readme/desktop-workflow.gif)

## 收集和整理，方便下一次使用

- **导入已有资料。** 从 Chrome、Edge、Firefox 或 Safari 导入书签，添加链接、本地文件，或将常用 Prompt/规则保存为笔记。
- **浏览时随手保存。** Chrome 扩展可保存当前网页的链接、可读内容和封面，保存前可以调整标题、内容和标签。
- **定制你的上下文组合。** 编辑最终交给 AI 的内容，用标签组织相关参考，为项目或常用任务保留一组可复用的上下文。

## 让 AI 帮你使用和管理上下文

通过 StashDock 的 MCP 和随附 Skill，AI 可以直接使用库里的参考，也能在对话中帮你维护收藏库。

- **寻找合适的参考。**“看看我的收藏库，推荐几份适合当前项目的资料。”
- **保存有用的上下文。**“把我们刚确定的写作规则存下来，下次继续用。”
- **整理收藏库。**“帮这些收藏规划标签，先给我看方案，再应用。”

积累设计参考、整理项目文档，或在不同 AI 应用间复用常用 Prompt/规则。同一份收藏库，可以随着你的工作方式不断拓展用法。

[添加至 Chrome](https://chromewebstore.google.com/detail/bbglcpbhnobjhgccjinejnnlcefelkee) · [安装指南](https://stashdock.app/guide#install-browser)

ChatGPT 插件和独立桌面应用可任选其一，也可以同时安装。两者都能独立使用，同时安装时共享同一份本地收藏库。

需要随手保存网页时，再安装 Chrome 扩展。安装并打开桌面应用或 AI 插件一次，完成配置后，即使两端都已退出，扩展仍能保存网页。

首次打开时，系统可能显示新应用的常规验证提示：

- **Windows：**如果出现「Windows 已保护你的电脑」，点击 **更多信息 → 仍要运行**。
- **Mac：**如果 macOS 提示无法打开 StashDock，进入 **系统设置 → 隐私与安全性 → 仍要打开**，再点击 **打开**。

## 本地存储，项目开源

收藏库保存在你的电脑上，收什么、将哪些参考交给 AI，由你决定。桌面应用与 ChatGPT 插件使用同一份本地收藏库，不同电脑之间不会自动同步。
